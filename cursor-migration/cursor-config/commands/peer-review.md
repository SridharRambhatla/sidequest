# /peer-review
Verify findings from another model.

## Input
Findings from peer review:
[PASTE FEEDBACK FROM OTHER MODEL]

## For EACH Finding
1. Verify it exists in code
2. If it doesn't, explain why
3. If it does, assess severity and add to fix plan

## Output
- Summary of valid findings
- Summary of invalid findings (with explanations)
- Prioritized action plan for confirmed issues

# /document
Update documentation after code changes.

## Steps
1. Identify changes
   - Check git diff or recent commits
   - Identify changed features/modules
   - Note new/deleted/renamed files
2. Verify current implementation
   - Read code, understand actual behavior
   - Note doc discrepancies
3. Update documentation
   - Update CHANGELOG.md under "Unreleased"
   - Use categories: Added, Changed, Fixed, Security, Removed
4. Style
   - Concise, practical, accurate, current
   - No assumptions

## Ask If Uncertain
If intent or user-facing impact is unclear, ask before writing.
